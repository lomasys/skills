# Manual de Tablerito

Tablerito es una herramienta para organizar el trabajo de un equipo en tableros con tarjetas.
Este manual explica cada función, sus límites y las preguntas frecuentes de los clientes.

## 1. Tableros

**¿Cómo funciona tableros (caso 1)?** En Tablerito, tableros se administra desde el menú principal. Abre el tablero, entra a Configuración y elige tableros. Los cambios se guardan solos y se ven al momento para todo el equipo. Si algo no aparece, recarga la página y revisa que tengas permiso de edición en ese tablero. El plan Gratis tiene límites en tableros; el plan Pro no tiene límites.
